# ssh-probe — Phase 0 の探り棒

**製品ではありません。**Issue 002（実機に繋がるか）と 003（D6・SSH ライブラリ）を
同時に潰すためだけのものです。**D6 が決まったら消します。**

`russh`（純 Rust）と `ssh2`（libssh2）で**同じことを両方やり、結果だけを出します。**

## 出力に何が載らないか

**接続先は 1 文字も出ません**（PRD §8）。

| 出ない | 出る |
|---|---|
| ホスト名 / IP / 利用者名 / パス | 繋がったか |
| ディレクトリの中身（名前） | **件数だけ** |
| ファイルの中身 | **文字コードの判定と統計だけ** |
| 秘密鍵 / パスフレーズ | ホスト鍵の**指紋**（`known_hosts` と突き合わせるため） |

**出力はそのまま貼れます。**

## 使い方

親のワークスペースから外してあります。ここで直接動かしてください。

```sh
cd tools/ssh-probe
cargo run --release -- --help
```

### 1. まず、何も繋がずに見る

**認証しません。接続もしません。**サーバーが提示している方式を読むだけです。

```sh
cargo run --release -- --host <ホスト> --offer-only
```

**002 の「古い鍵交換方式・暗号方式が残っているか」は、ここに出ます。**
`diffie-hellman-group1-sha1` や `3des-cbc` や `ssh-dss` が並んでいたら、そのサーバーは古い側です。

### 2. 実際に繋ぐ

**ssh-agent 経由が既定です。**鍵ファイルを直接使う場合だけ `--key` を付けます。

```sh
# ssh-agent（推奨）
cargo run --release -- --host <ホスト> --user <利用者>

# 鍵ファイル。パスフレーズがあるならその場で聞きます
cargo run --release -- --host <ホスト> --user <利用者> --key ~/.ssh/id_ed25519 --ask-passphrase
```

**パスフレーズを引数で渡す口は用意していません。**シェルの履歴に平文で残るためです
（product-baseline §14）。

### 3. 文字コードを見る

Tera Term の漢字コード設定にあたる問題です。**中身は出ません。**

```sh
cargo run --release -- --host <ホスト> --user <利用者> \
  --sftp-path /var/log --sniff /var/log/<何かのログ>
```

`UTF-8` 以外（`Shift_JIS` / `EUC-JP` / `ISO-2022-JP`）が出たら、
**端末だけでなく `read_file` で AI に渡す文字列も同じ問題を踏みます。**
`.claude/decisions.md` に書いてください。

## ホスト鍵について

**この探り棒はホスト鍵を検証せずに受け入れます。**繋がるかを見るのが目的だからです。
代わりに**指紋を出力する**ので、`known_hosts` と突き合わせてください。

**製品側では受け入れません。**`russh` の `check_server_key` は既定で全部拒否で、
dbboard の ADR-0069 も「blind-accept を型で作らせない」形にしています。同じ扱いにします。
