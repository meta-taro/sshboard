# 配布ページ用のキャプチャ

配布ページ（`site/`）に載せる画面写真を、**架空の設定の上で**撮るための一式です。

> **キャプチャは、架空の設定を入れた上にしてください。**
> —— 運用者・2026-09-18

**この製品の画面には、必ず接続先が写ります**（ホスト名 / IP / 利用者名 / パス）。
CLAUDE.md の禁止事項 4 と D26 があるため、**実際の接続のまま撮ったものは出せません。**
ここに在る設定は**誰のサーバーでもなく**、向き先は手元のテスト用コンテナだけです。

## 撮る手順

```sh
sh tools/test-server/up.sh        # 手元のサーバーを建てる
ssh-add tools/test-server/.key    # **これを忘れると繋がりません**
sh tools/demo/use-demo.sh         # 架空の設定へ入れ替える（いまの設定は退避）
```

**`ssh-add` は要ります。**架空の設定は `key_path` を書いていない ——
つまり **ssh-agent を使う形**（推奨の形）なので、鍵が agent に入っていないと
［開く］で止まります。**実際にここで 1 回止まりました**（2026-09-18）。

**アプリを立ち上げ直してください。**接続一覧を読むのは起動時です。

そのうえで、**5 枚**撮ります。タブの並び順どおりです。

| # | タブ | 何が写っていてほしいか | ファイル名 |
|---|---|---|---|
| 1 | 接続 | 3 件が色とタグ付きで並んでいる所 | `site/shots/connections.png` |
| 2 | ファイル | 左にサーバー、右に手元。**片方のパンくずが見えている** | `site/shots/files.png` |
| 3 | 端末 | 何か打ったあと。**［止める］が見えている** | `site/shots/console.png` |
| 4 | 操作の記録 | `[Human]` と `[AI]` の札が**両方**出ている所 | `site/shots/band.png` |
| 5 | ログ | 繋がるまでの段が並んでいる所 | `site/shots/diag.png` |

**4 枚目は、AI を繋いでからでないと `[AI]` の行が出ません。**
`claude mcp add`（README 参照）で繋いで、何か 1 つ読ませてから撮ってください。

## 撮り終えたら

```sh
sh tools/demo/use-demo.sh back    # 元の設定へ戻す
```

**戻すのを忘れないでください。**忘れると、次に開いたとき**自分の接続が 1 件も無い**
画面になります（消えてはいません。退避してあるだけです）。

## 置き方

`.gitignore` が `*.png` を落としています。**これは画面写真を commit history へ
焼き付けないための禁止**で（D26 / PRD §8）、**緩めません。**

**架空の設定で撮ったものだけ**、`site/shots/` に例外を開けて置きます ——
**この 1 ディレクトリだけ**です。`site/shots/` へ入れてよいのは、

- **架空の設定で撮ったもの**（`connections.demo.toml` の 3 件）
- **撮った人が中身を見て、接続先が 1 つも写っていないと確かめたもの**

の両方を満たすものだけ。**AI は撮りません。AI は検めません。**
ここは人が見て、人が置く所です（baseline §19 / §29）。
