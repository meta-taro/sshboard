# 005. `tail -f` を GUI と MCP へ同時に流す／ANSI とプレーンを分ける（Phase 0）

## なぜ

障害調査の主作業はログの追尾です。
ここで **GUI 側は色付きで見え、MCP 側はプレーンなテキストで返る**必要があります。

MCP へ ANSI エスケープが混ざったまま返すと、AI が読む文字列にゴミが入ります。
GUI から色を落とすと人が読みにくくなります。**同じ 1 本の出力を、面ごとに違う形で出す。**

## やること

- 実機で `tail -f` 相当を流す
- GUI（xterm.js）へは ANSI のまま描画する
- MCP へはプレーンなテキストで返す
- **止められること**を確認する（人が AI の実行を止め、同じセッションで続けられる・PRD §4-3）

## 完了条件

- [ ] 同じ 1 本の出力が、GUI と MCP の両方へ同時に出た
- [ ] MCP 側の文字列に ANSI エスケープが 1 つも混ざっていない
- [ ] GUI 側は色が保たれている
- [ ] 流している途中で人が止められ、止めたあと人が同じセッションで続けられた

## やらないこと

- ANSI の解釈を自前で書かない（xterm.js に任せる・D7）
