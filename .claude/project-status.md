へ回りました。**sshboard のセッションを開く道具なので、ここに要点だけ残します。**

- 文字が小さい → 既定を 16pt → **18pt**。決め手は読みやすさではなく**桁数**で、

- **Terminal.app の ANSI パレットは AppleScript から触れません**
  （scriptable property は background / normal text / bold text / cursor の 4 つだけ）。
